# LALAINATOR

A horror game. Lala went out after dark, and more than one of her came home.
Find the fake Lalas in a dark ink-drawn city, unmask them with the Lalainator, and ring the tower bell when they are gone.

Play alone or with up to 3 friends (Host co-op, then share the 6-letter room code).

Play: open `index.html` in a browser, or visit the GitHub Pages site.
